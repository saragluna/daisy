# Daisy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the app to Daisy and make it directly manage `copilot-api` and `litellm-proxy` as child processes with service controls, config editing, models, and logs.

**Architecture:** Replace launchd-oriented service control with a Daisy-owned process manager. Keep the existing SwiftUI shell, but change navigation from Status/Models/Logs to Services/Models/Logs/Config and make logs line-based.

**Tech Stack:** SwiftPM, SwiftUI, Foundation `Process`, local file IO, UserDefaults cache.
